# AICG Workbench V1.0

中文 · [English](README.en.md)

**Seedance 折扣 API：請聯絡開發者。**

AICG Workbench 让人与 Agent 通过开放的本机 MCP 接口，在同一张画布上协作创作图片和影片。你在可视界面决定方向、检查结果；获授权的 Agent 读取画布、整理任务、调整提示词与参数，并协助布置镜头、处理结果和影片顺序。本版运行于 Windows，支持同机标准 stdio MCP，不绑定特定 Agent 品牌；实际连接仍取决于客户端兼容性与授权范围。

## 安装与上手

1. 从 GitHub Releases 下载 Windows x64 安装包与 `SHA256SUMS.txt`。核对 SHA-256 后解压。
2. 按包内 `START-HERE.zh-CN.md` 安装。首次安装使用两个独立目录存放程序和资料，保留旧工程。
3. 启动 `START-AICG.cmd`。先用一张测试图片建项目、配置任务并保存。
4. 按包内 `DEPENDENCIES.md` 检查媒体工具。视频探测、解码和合并使用自装的 FFmpeg 和 ffprobe。保留的旧媒体校验路径可能需要 Python。安装包不会自动下载工具或模型。

## 现在可以做什么

- 在任务框中编辑提示词、模型及常用参数。在「来源」查看素材、结果和记录。简体中文和英文可在设置切换。
- 使用已适配的图片和视频模型。视频入口包含文字、首帧、首尾帧、多参考和参考影片；可用操作与参数取决于模型、账户和官方接口。
- 使用同机 AUTOMATIC1111 Stable Diffusion WebUI v1.10.1 的 API。配置无认证的 `http://127.0.0.1` 服务，可读取模型列表和执行单张 PNG 文生图。该连接不提供参考图或影片生成。未知协议可以保存为自定义草稿。当前未提供 Ollama 或 LM Studio 执行连接。
- 在摄影棚布置最多四个人偶、调整姿势与相机，并把本地示例图送回画布。影片可按任务排序后直接拼接；片段符合兼容条件时保留音轨。
- 在「Agent 与 MCP 连接」为当前项目或素材库建立、限制及撤销授权。使用运行在同一台 Windows 电脑上的标准 stdio MCP 客户端。包内 `MCP-CLIENT-GUIDE.zh-CN.md` 提供配置步骤，`AGENT-GUIDE.zh-CN.md` 说明工具、实际权限及例子。首次连接可先读状态、修改合成提示词并撤销。

## 开放 MCP：让人和 Agent 在同一张画布协作

AICG 不只是让 Agent 生成一段提示词。它提供本机标准 **stdio MCP** 接口，让你授权的 Agent 读取当前工作台状态，并通过工作台本身的操作修改画布。你继续使用可视界面，Agent 使用同一套任务、素材、模型参数与结果逻辑，不需要另维护一份脱离画布的计划。

**不绑定 Codex 或其他特定品牌。** 支持在同一台 Windows 电脑上运行本地 stdio MCP 程序的客户端，可以配置本安装自带的 `AICG-MCP.exe`。这不等于所有 Agent 都已通过测试；只提供远程连接器、无法运行本地程序的云端客户端，不能直接接入本版。

### 已实现的协作接口

以下是已实现接口的范围，不是每种客户端、每个模型均已端到端验证的承诺。具体可用操作仍受连接权限、当前项目、模型能力和素材状态约束。

| 你要做的事 | Agent 可以怎样协作 |
| --- | --- |
| 了解项目与画布 | 查询工作台状态，列出、创建、打开获授权的项目；读取已套用的画布、任务和素材信息。较长字段可分页补读。 |
| 整理任务 | 修改提示词、文字、节点位置、连线及任务选材；读取任务真正可用的模型和参数，再写回同一任务。支持对应画布修改的撤销。 |
| 查看与导入素材 | 读取经过校验的素材信息、PNG 预览或分页原始字节；让你在本机选择素材，或按明确请求导入。导入工作台不等于向生成服务上传。 |
| 协助生成 | 预览已套用任务的模型、提示词、参数和素材；请求生成后，由你在本机确认。查询原任务历史、恢复下载或停止等待，不把未知结果自动当成失败重发。 |
| 布置摄影棚 | 调整最多四个人偶的姿势、位置、关节以及相机、灯光；渲染本地示例图；读取或保存姿势库。 |
| 整理结果和影片 | 查看、接受指定结果版本；排序影片任务，严格拼接符合兼容条件的现有片段并保留音轨。媒体操作需要相应外部工具。 |
| 保存与连接设置 | 在授权范围内保存、备份或恢复新副本；读取和修改非秘密模型连接设置。整库操作需要整库授权，单项目连接不能越权静默保存整库。 |

工具入口包括 `aicg_workbench_status`、`canvas_context_read`、`canvas_context_execute`、`canvas_context_undo`、`canvas_task_models`、`canvas_workbench_catalog` 和摄影棚／严格合并工具。`canvas_workbench_catalog` 可查询当前操作目录；Agent 应先读实际状态和能力，不猜项目 ID、素材版本或参数。

### 可以这样配合

这些是使用方式示例，不代表已对每个客户端实测：

- **你定方向，Agent 整理任务：**“读取当前画布，把这三个影片任务的提示词整理成统一风格，保留原素材与模型，先不要生成。”你在画布检查修改，不满意时撤销。
- **你选素材，Agent 准备生成：**“用我选定的首尾帧准备这个影片任务，检查模型是否支持，先给我预览。”Agent 整理任务；涉及真实生成时仍由你在本机核对并批准。
- **你看镜头，Agent 调场景：**“把指定人物放到画面左前方，调整相机，再渲染一张示例图供我检查。”这属于摄影棚参考图操作，不是自动请求供应商生图。
- **你决定成片，Agent 整理顺序：**“按指定顺序排列已完成影片，检查能否直接拼接，不能兼容就先告诉我。”不会把严格拼接悄悄变成转码、配乐或重新生成。

### 如何连接

1. 安装并打开工作台，进入 **设置 → Agent 与 MCP 连接**。
2. 为实际使用的客户端建立独立连接，选择只读、可撤销编辑或完整工作台操作，并限定当前项目或素材库。按需启动是单独选项。
3. 复制工作台生成的 MCP 配置，填入客户端的本地 stdio MCP 设置：`command` 为本安装的 `AICG-MCP.exe`，`args` 包含 `--stdio --connection` 和该连接 ID，`cwd` 为安装目录。使用生成的真实值，不照抄别人的路径或连接 ID。
4. 先让 Agent 查询工作台状态、读取一个测试项目；需要编辑时，先尝试修改一条测试提示词并撤销。
5. 不再使用时，在工作台撤销该连接。不要公开连接配置或交给不信任的客户端。

连接不需要捆绑 Codex、Node.js 或 PowerShell 7。Agent 不能读取 Key 明文、创建自己的连接授权或代替你批准付费。密钥只在本机输入窗口填写。授权也不能防御同一 Windows 账户下的恶意软件，因此应只连接可信客户端。

详见[客户端接入指南](docs/MCP-CLIENT-GUIDE.zh-CN.md)与[工具、权限和操作示例](docs/AGENT-GUIDE.zh-CN.md)。指南中提及的旧版客户端结果，不应当成当前安装包已重测全部客户端。

### MCP 验证到哪一步

- **当前 V1.0 安装包：**新目录安装、文件校验、后台 Electron 启动和原生 stdio 测试程序已通过；发现 31 个工具，协议版本 `2025-06-18`，读回 `applicationConnected` 与 `ready`。测试程序不是实际品牌 Agent，也没有逐项执行全部 31 个工具。
- **历史安装版：**有真实 Codex CLI 的合成编辑、读回与撤销回归。当前包未重新跑这一品牌客户端流程；Codex 桌面也不能因此算通过。
- **尚未验证：**当前包的 Claude Code 成功工具调用、其他客户端矩阵、真人完整前台流程以及真实供应商生成。接口已实现与真生成验证是两回事。
- **接入边界：**本版为同机 Windows stdio，不提供远程 HTTPS MCP 或 macOS 安装包。

## 生成服务与费用

工作台允许使用自己的生成服务账户。Key 在本机窗口输入。真实生成或上传前请核对模型、接收方、资料和费用，并在工作台批准。供应商收费、可用额度和能力以你的账户与服务协议为准。未知提交先查原任务，避免重复发送。

## 验证范围

Windows 候选的任务 UI 已在隔离 Electron 用合成项目验证。安装和本地启动见包内 `VERIFICATION.md`。真供应商生成、真 Stable Diffusion 生成、干净 Win10/Win11 机器矩阵及部分客户端还待验证。本版提供 Windows 安装包，MCP 接入范围为同机 stdio。历史现场整屏卡死尚未重现，根因未确认。
