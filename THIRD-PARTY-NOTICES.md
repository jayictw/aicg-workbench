# Third-party licensing

The source lockfile identifies direct and transitive npm dependencies. Runtime
dependencies used by the installer retain their original notices. Electron
and Chromium notices are included in the installer, where their component
notices and the package inventory can be read in THIRD-PARTY-NOTICES.md.
These components are subject to their own licenses.

External tools such as FFmpeg, ffprobe, Python, and Agent clients are obtained
and licensed separately. This source review snapshot includes no separately
distributed fonts, models, media fixtures, user data, third-party installers,
or binary dependencies. Project MIT terms, once finalized, apply to code the
project has the right to license.
